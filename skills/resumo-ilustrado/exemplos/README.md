# exemplos/

Modelos de referencia (imagens ou PDFs) enviados pelo usuario, mostrando o formato visual e estrutural esperado de um resumo ilustrado. A skill resumo-ilustrado usa esses arquivos como referencia de layout, hierarquia e estilo ao produzir novo conteudo - inclusive para materiais internacionais (paises/), onde o padrao de marca pessoal (brand/) nao se aplica e esses exemplos passam a ser a principal referencia visual.
