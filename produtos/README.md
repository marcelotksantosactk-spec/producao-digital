# produtos/

Uma pasta por produto. Estrutura sugerida para cada produto novo:

```
produtos/<nome-do-produto>/
  briefing.md      -> o que e o produto, publico, preco, formato de entrega
  fontes/            -> fontes e referencias usadas na pesquisa
  materiais/         -> resumos, mapas mentais, apostilas, questoes
  imagens/           -> imagens e ilustracoes do produto
  mockups/           -> mockups do produto (tablet, notebook, celular, etc.)
  landing-page/      -> landing page desse produto
```

Copie essa estrutura ao comecar um produto novo.
