# Chile

Contexto de partida para producao de materiais didaticos no Chile. Validar sempre as informacoes abaixo com a skill pesquisa-edital antes de usar, pois regras institucionais mudam com frequencia.

## Tipos de prova

- Concurso publico: processos via Servicio Civil / Alta Direccion Publica (ADP), alem de concursos proprios de cada instituicao (Poder Judicial, Contraloria, etc.).
- Vestibular / admissao universitaria: PAES (Prueba de Acceso a la Educacion Superior), aplicada pelo DEMRE - substituiu a antiga PSU.
- Exame de habilitacao profissional (equivalente a OAB): no Chile, apos concluir a faculdade de Direito (5-6 anos), e necessario cumprir uma pratica profissional supervisionada (cerca de 6 meses, geralmente via Corporacion de Asistencia Judicial - CAJ) e depois prestar um exame de conhecimentos perante a Corte Suprema, com juramento final. E mais proximo estruturalmente de um exame de habilitacao do que o caso peruano, mas nao e administrado por uma entidade tipo "OAB" e sim pelo proprio Poder Judiciario - confirmar a situacao atual (incluindo mudancas recentes de exigencias) via pesquisa-edital/pesquisa-conteudo antes de assumir como definitivo.
